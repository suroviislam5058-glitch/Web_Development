👌Advanced Web Technology — Short Notes

o	REST API: Frontend and backend communicate through HTTP methods like GET, POST, PUT, DELETE. 

o	JWT Authentication: Secure login system using tokens. 

o	WebSockets: Real-time communication, useful for chat, live notifications, dashboards. 

o	AJAX / Fetch API: Updates webpage data without refreshing the page. 

o	TypeScript: JavaScript with static typing; improves large-project reliability. 

o	Node.js: JavaScript runtime for backend development. 

o	NestJS: Structured Node.js framework for scalable backend APIs. 

o	React / Angular: Modern frontend frameworks/libraries for dynamic web applications. 

o	ORM: Connects application code with databases, e.g., Prisma, TypeORM. 

o	Middleware: Processes requests before they reach the main controller. 

o	Caching: Stores frequently used data to improve speed. 

o	Web Security: HTTPS, CORS, CSRF protection, XSS prevention, input validation. 

o	Docker: Packages an application and its dependencies into containers. 

o	CI/CD: Automatically tests and deploys applications. 

o	Cloud Deployment: Hosting web applications on services such as AWS, Azure, or Render. 

o	Microservices: Divides a large application into smaller independent services.
